# APLSI

Material y trabajo de cursada de **APLSI** (Actuación Profesional del Licenciado en Sistemas de Información de las Organizaciones), FCE-UBA — Cátedra Piorun, Curso 3 (Prof. Luis Campos).

Este repositorio es un espacio de estudio: contiene apuntes, diapositivas, transcripciones de clases y los entregables del trabajo práctico de consultoría de la materia. No es un proyecto de software.

## Estructura

- **`000_Bibliografía/`** — Material bibliográfico de la cátedra.
- **`000_Cronograma/`** — Cronograma de clases y entregas del cuatrimestre.
- **`000_Presentaciones/`** — Diapositivas y resúmenes de cada clase.
- **`000_Transcripcion_Clases/`** — Transcripciones de las clases dictadas.
- **`00__Identidad_Consultora/`** — Plantilla de presentaciones, paleta de colores y logo de la consultora del grupo.
- **`01__Caso_de_Negocio/`** — Entregables del caso de negocio y relevamiento organizacional del cliente elegido por el grupo.

## Notas
